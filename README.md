# Simulation d'Écosystème : Loups & Moutons

Ce projet implémente une simulation d'écosystème de type "Proie-Prédateur" en Python. Elle simule les interactions naturelles entre trois entités principales : l'**Herbe** (ressource), les **Moutons** (proies) et les **Loups** (prédateurs) sur une grille.

Le projet offre deux modes de visualisation : une interface graphique animée avec **Pygame** et une version textuelle pour la console.

## Prérequis

Pour exécuter ce projet, il faut installer ainsi que les bibliothèques suivantes :

* **Numpy** : Pour la gestion des tableaux et des opérations aléatoires.
* **Pygame** : Pour l'affichage graphique.

## Lancement de la simulation 
Pour lancer une simulation sans interface graphique : taper **python main.py** dans le bash
Pour lancer une simulation avec interface graphique : taper **python main_guy.py** dans le bash

## Details des fichiers
**entities.py** : classes des entités (grass, wolf, sheep)
**grid.py** : classe de la grille
**main.py** : fichier main (sans interface graphique)
**main_gui.py** : fichier main (avec interface graphique)
